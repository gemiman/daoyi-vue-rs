## 1. 概述

本Agent SDK是监控端开发包，使用TypeScript或JavaScript集成监控座席控制功能，支持VUE开发。接口功能分类如下：

| 接口分类           | 接口说明 |
|:---------------|:-----|
| AgentControl接口 | 班长功能 |

| 端口   | 协议  | 用途               |
|:-----|:----|:-----------------|
| 9059 | tcp | websocket连接访问服务器 |

### 1.1 工厂方法创建接口

`var api = VcMonitorApi.createAgentControl(host,port,ssl);`

host:服务id
port:端口
ssl:参数传递的”ws”或”wss”

### 1.2 创建实例之后设置所需的回调函数，请参见”3. API事件定义”章节

`api.setAgentListEventListener(...)`

等等，演示程序将收到的事件在浏览器console输出并限制当前状态下的操作

### 1.3 UI使用api调用接口方法，请参见”2. API接口定义”章节。

`api.adminLogin(...);`

### 1.4 在Vue项目中使用npm安装监控SDK:

`npm i vcswitch-mnt-api -S`

Agent SDK和服务端采用WebSocket长连接，由Agent SDK内部的AccessWebSocketClient类实现。相关的接口定义和事件接口信息将会在后面章节详细介绍。

## 2. API接口定义

### 2.1 登录adminLogin()

登录接口指的是班长登入输入信息以便查询组内成员的状态以及注册订阅信息，一般地在登录业务系统成功后再调用。

| 字段名称   | 字段类型 | 说明  | 示例                   |
|:-------|:-----|:----|:---------------------|
| device | 字符串  | 分机号 | 8003                 |
| queue  | 字符串  | 技能组 | 888888@172.16.20.181 |

**触发事件**

| 事件     | 设置回调           | 说明                        |
|:-------|:---------------|:--------------------------|
| 成员状态列表 | AgentListEvent | setAgentListEventListener | 详见3.2座席列表回调 |

**注：V1.0.4改动queue在不传前面888888@的情况下支持全局跨技能组获取所有座席状态变更的推送**

### 2.2 登出 logout()

断开WebSocket连接。

### 2.3 强制置闲 forceFree()

班长强制将组内某个座席的状态设置为空闲，即就绪。若座席正在通话中则会报通话中提示，该操作将无效。

| 字段名称        | 字段类型 | 说明     | 示例   |
|:------------|:-----|:-------|:-----|
| AgentDevice | 字符串  | 组内座席分机 | 8002 |

**触发事件**

| 事件   | 设置回调                   | 说明                                |
|:-----|:-----------------------|:----------------------------------|
| 状态变化 | AgentStatusChangeEvent | setAgentStatusChangeEventListener | 详见3.1座席状态回调 |

### 2.4 强制置忙 forceBusy()

班长强制将组内某个座席的状态设置为忙碌，即未就绪。若座席正在通话中则会报通话中提示，该操作将无效。

| 字段名称        | 字段类型 | 说明     | 示例   |
|:------------|:-----|:-------|:-----|
| AgentDevice | 字符串  | 组内座席分机 | 8002 |

**触发事件**

### 2.5 强制退出 forceLogout()

班长强制将组内某个座席的状态设置为登出。若座席正在通话中则会报通话中提示，该操作将无效。

| 字段名称        | 字段类型 | 说明     | 示例   |
|:------------|:-----|:-------|:-----|
| AgentDevice | 字符串  | 组内座席分机 | 8002 |

**触发事件**

| 事件   | 设置回调                   | 说明                                |
|:-----|:-----------------------|:----------------------------------|
| 状态变化 | AgentStatusChangeEvent | setAgentStatusChangeEventListener | 详见3.1座席状态回调 |

### 2.6 监听 forceListen()

班长席发起对组内座席的监听。

| 字段名称        | 字段类型 | 说明     | 示例   |
|:------------|:-----|:-------|:-----|
| AgentDevice | 字符串  | 组内座席分机 | 8002 |

不触发事件。若班长登录了座席系统则会触发状态回调事件

### 2.7 强插 forceConference()

班长席发起对组内座席的强插，即班长席加入和客户的三方通话。

| 字段名称        | 字段类型 | 说明     | 示例   |
|:------------|:-----|:-------|:-----|
| AgentDevice | 字符串  | 组内座席分机 | 8002 |

不触发事件。若班长登录了座席系统则会触发状态回调事件

### 2.8 耳语 forceWhisper()

班长席发起对组内座席的耳语，即班长的话语仅座席能听见、客户是听不见的。

| 字段名称        | 字段类型 | 说明     | 示例   |
|:------------|:-----|:-------|:-----|
| AgentDevice | 字符串  | 组内座席工号 | 8002 |

不触发事件。若班长登录了座席系统则会触发状态回调事件

### 2.9 强制挂断 forceHangup()

班长席发起对组内座席的强制挂机，注意：该操作将引起座席和客户间通话的立即中断。

| 字段名称        | 字段类型 | 说明     | 示例   |
|:------------|:-----|:-------|:-----|
| AgentDevice | 字符串  | 组内座席分机 | 8002 |

目前返回值总是true，可忽略。

**触发事件**

| 事件   | 设置回调                   | 说明                                |
|:-----|:-----------------------|:----------------------------------|
| 状态变化 | AgentStatusChangeEvent | setAgentStatusChangeEventListener | 详见3.1座席状态回调 |

### 2.10 强制拦截 forceIntercept()

班长席发现组内座席异常通话，就将座席的来电拦截过来，注意：该操作将引起座席和客户间通话的立即中断。

| 字段名称        | 字段类型 | 说明     | 示例   |
|:------------|:-----|:-------|:-----|
| AgentDevice | 字符串  | 组内座席分机 | 8002 |

目前返回值总是true，可忽略。

**触发事件**

| 事件   | 设置回调                   | 说明                                |
|:-----|:-----------------------|:----------------------------------|
| 状态变化 | AgentStatusChangeEvent | setAgentStatusChangeEventListener | 详见3.1座席状态回调 |

## 3. API事件定义

### 3.1 座席状态回调setAgentStatusChangeEventListener()

状态改变后回调该接口，其中AgentStatusChangeEvent定义如下：

| 字段名称     | 字段类型   | 说明                     | 示例                   |
|:---------|:-------|:-----------------------|:---------------------|
| EvtName  | 字符串    | AgentStatusChangeEvent |                      |
| Data     | Object | 包含以下五个参数               |                      |
| AgentId  | 字符串    | 座席工号                   | 8003@172.16.20.181   |
| Device   | 字符串    | 座席分机                   | 8002@172.16.20.181   |
| Status   | 字符串    | 状态                     | 10                   |
| Queue    | 字符串    | 队列,多个组用逗号隔开            | 888888@172.16.20.181 |
| DateTime | 字符串    | 事件时间                   | 2023-02-01 15:14:05  |

状态分类：0 就绪(Available (On Demand)), 1 未就绪, 2 呼入的话后处理, 3 小休, 4 就餐, 5 培训, 9 外呼的话后处理, 10 未登录,
11 登录, 12 通话中, 13 外呼拨号, 14 呼入振铃, 16 就绪(Available)

### 3.2 座席列表回调 setAgentListEventListener()

返回组长下面座席列表，其中AgentListEvent定义如下：

| 字段名称     | 字段类型         | 说明             | 示例                   |
|:---------|:-------------|:---------------|:---------------------|
| EvtName  | 字符串          | AgentListEvent |                      |
| List     | Object Array | 数组内包含以下五个参数    |                      |
| AgentId  | 字符串          | 座席工号           | 8003@172.16.20.181   |
| Device   | 字符串          | 座席分机           | 8002@172.16.20.181   |
| Status   | 字符串          | 状态             | 10                   |
| Queue    | 字符串          | 队列,多个组用逗号隔开    | 888888@172.16.20.181 |
| DateTime | 字符串          | 事件时间           | 2023-02-01 15:14:05  |

### 3.3 未接来电排队数量setMembersCountEvent()

用户来电能获取队列正在排队的数量，其中MembersCountEvent定义如下：

| 字段名称     | 字段类型   | 说明             | 示例                   |
|:---------|:-------|:---------------|:---------------------|
| EvtName  | 字符串    | AgentListEvent |                      |
| Data     | Object | 包含以下三个参数       |                      |
| Queue    | 字符串    | 队列,多个组用逗号隔开    | 888888@172.16.20.181 |
| Count    | 字符串    | 排队数            | 1                    |
| DateTime | 字符串    | 事件时间           | 2023-02-01 15:14:05  |

### 3.4 提示被呼客服正通话中回调setAgentOnCallEventListener()

客服a磋商、转接客服b时正在通话中回调接口，其中AgentOnCallEvent定义如下：

| 字段名称    | 字段类型 | 说明               | 示例      |
|:--------|:-----|:-----------------|:--------|
| EvtName | 字符串  | AgentOnCallEvent |         |
| Called  | 字符串  | 被呼客服分机           | 8002    |
| State   | 字符串  | calling          | calling |

### 3.5 提示网关告警事件setGatewayWarningEventListener()

网关线路通路告警事件，其中GatewayWarningEvent定义如下：

| 字段名称    | 字段类型 | 说明                  | 示例                                   |
|:--------|:-----|:--------------------|:-------------------------------------|
| EvtName | 字符串  | GatewayWarningEvent |                                      |
| Gateway | 字符串  | 网关id                | 6b7f9714-64c4-47b2-97bb-db0372e59f34 |
| Profile | 字符串  | 内呼外呼配置              | external、internal                    |
| Status  | 字符串  | 状态                  | DOWN（状态为DOWN时发出告警）                   |

### 3.6 登出事件setLogoutEventListener()

WebSocket登出事件，其中LogoutEvent定义如下：

| 字段名称    | 字段类型 | 说明          | 示例   |
|:--------|:-----|:------------|:-----|
| EvtName | 字符串  | LogoutEvent |      |
| Code    | 字符串  | 错误码         | 1001 |
| Cause   | 字符串  | 错误描述        | 正常登出 |

### 3.7 座席实时聊天事件setDetectedSpeechEventListener()

返回座席实时聊天信息，其中DetectedSpeechEvent定义如下：

| 字段名称        | 字段类型   | 说明                  | 示例                                   |
|:------------|:-------|:--------------------|:-------------------------------------|
| EvtName     | 字符串    | DetectedSpeechEvent |                                      |
| Data        | Object | 包含以下五个参数            |                                      |
| ConnId      | 字符串    | 会话ID                | cc1604f5-31a4-4d3f-88eb-a5f9af68021b |
| Speaker     | 字符串    | 讲话方                 | 8017                                 |
| SpeakerUUID | 字符串    | 讲话方uuid             | cc1604f5-31a4-4d3f-66eb-a5f9af68021b |
| Content     | Object | 内容                  | 您好，有什么可以帮您？                          |
| DateTime    | 字符串    | 时间                  | 2023-02-01 15:14:05                  |

错误编码定义如下：

| 数值   | 说明                                   |
|:-----|:-------------------------------------|
| 1000 | 正常登出                                 |
| 1001 | 终端离开，可能因为服务端错误，也可能因为浏览器正从打开连接的页面跳转离开 |
| 1002 | 由于协议错误而中断连接                          |
| 1003 | 由于接收到不允许的数据类型而端口连接                   |
| 1005 | 表示没有收到状态码                            |
| 1006 | 连接非正常关闭                              |
| 1009 | 由于收到过大的数据帧而断开连接                      |
