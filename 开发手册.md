# 开发手册
## 创建项目
```shell
git clone git@github.com:gemiman/daoyi-vue-rs.git
```
## 初始化项目
```shell
cargo init
```
## 设置 server.port
- DY__SERVER__PORT=8080
- 完整示例
```shell
DY__SERVER__PORT=8080 cargo run --bin daoyi-demo
```
## 运行项目
```shell
ACTIVE_PROFILE=local
```
## 安装 sea-orm-cli
```shell
cargo install sea-orm-cli
```

## WebSocket / 消息队列 (MQ) 开发

项目通过 WebSocket 配合 Redis Pub/Sub 实现了跨集群的消息广播功能（对标 Java 版的 WebSocket 消息机制）。

### 1. 添加新的消息监听器 (Listener)

如果你想处理前端通过 WebSocket 发送的特定类型消息，请按照以下步骤操作：

#### 步骤 1：定义消息结构

在业务模块（如 `infra`）中定义请求和响应的 VO 对象：

```rust
#[derive(Debug, Deserialize)]
pub struct MyMessageReq {
    pub content: String,
}

#[derive(Debug, Serialize)]
pub struct MyMessageResp {
    pub reply: String,
}
```

#### 步骤 2：实现 WebSocketMessageListener

实现 `WebSocketMessageListener` trait：

```rust
use daoyi_common_support::websocket::{WebSocketMessageListener, WebSocketSession, WebSocketMessageSender};
use async_trait::async_trait;

pub struct MyMessageListener {
    pub sender: Arc<WebSocketMessageSender>,
}

#[async_trait]
impl WebSocketMessageListener for MyMessageListener {
    async fn on_message(&self, session: Arc<WebSocketSession>, content: serde_json::Value) {
        if let Ok(req) = serde_json::from_value::<MyMessageReq>(content) {
            // 处理逻辑
            let resp = MyMessageResp { reply: format!("收到: {}", req.content) };

            // 发送回执消息
            self.sender.send_by_user(1, session.user_id.as_ref().unwrap(), "my-message-reply", resp).await;
        }
    }

    fn get_type(&self) -> &str {
        "my-message-test" // 对应前端消息中的 type 字段
    }
}
```

#### 步骤 3：注册监听器

在对应模块的 WebSocket 初始化逻辑中（通常是 `ws/mod.rs`）注册该监听器：

```rust
state.ws_manager.add_listener(Box::new(MyMessageListener {
sender: state.ws_sender.clone(),
})).await;
```

### 2. 服务端主动推送消息

在任何可以访问到 `AppState` 的地方（如 Controller 或 Service），可以直接调用 `ws_sender`：

```rust
// 推送给指定类型的全体在线用户 (1: Admin, 2: Member)
state.ws_sender.send_by_user_type(1, "notice-push", notice_vo).await;

// 推送给指定 ID 的在线用户
state.ws_sender.send_by_user(1, "1024", "order-update", order_vo).await;
```

> **注意**：由于集成了 Redis 广播，上述推送会自动分发到集群中的所有节点，确保连接在其他服务器上的用户也能收到消息。
